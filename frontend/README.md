# frontend

지구본 여행일지 웹 화면. React 19 + Vite + TypeScript, 지구본은 [react-globe.gl](https://github.com/vasturiano/react-globe.gl)(three.js)을 쓴다.

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # 타입 검사 + dist/ 빌드
npm run lint
```

## NFR-01 성능 검증 페이지

지금은 첫 화면이 성능 검증 페이지(`src/perf/`)다. 가짜 핀(기본 1,000개)을 띄운 지구본을 돌리며 화면 왼쪽 위에 FPS를 표시한다.

### 휴대폰에서 재기

1. PC와 휴대폰을 같은 Wi-Fi에 연결한다.
2. `npm run dev:lan`을 실행하고, 출력의 `Network:` 주소(예: `http://192.168.0.10:5173`)를 휴대폰 브라우저로 연다. 연결이 안 되면 Windows 방화벽에서 Node.js의 개인 네트워크 접근을 허용한다.
3. 조건을 고른 뒤 10초 동안 두면 판정이 나온다. 조건을 바꾸면 기록을 처음부터 다시 잰다.

| 표시 | 뜻 |
| --- | --- |
| fps | 최근 0.5초 동안의 프레임 수 |
| 평균·최저 | 최근 10초 동안 0.5초 구간 값들의 평균과 최저 |
| 가장 긴 프레임 | 최근 0.5초 안에서 가장 오래 걸린 프레임(끊김 정도) |
| 판정 | 10초 동안 최저가 30fps 이상이면 통과 |

화면 갱신 빈도(60Hz·120Hz)보다 높게는 나오지 않는다. 탭을 가렸다 돌아온 구간은 기록에서 뺀다. 개발 서버는 빌드보다 느릴 수 있으니, 최종 확인은 `npm run build && npx vite preview --host`로 한다.

### 측정 조건

- **핀 개수**: 100 / 1,000 / 3,000. 클러스터링(FR-22) 없이 전부 그리므로 실제 화면보다 나쁜 조건이다.
- **핀 그리는 방식**: 개별 메시(누를 수 있음, FR-04), 병합 메시(가장 빠르지만 누를 수 없음), HTML 요소(DOM).
- **해상도 배율**: 1, 2, 기기 값. globe.gl 기본값은 기기 값을 2로 제한한 값이다.
- **그 밖의 부하**: 자동 회전, 타임랩스 경로 호 50개(FR-26), 안티에일리어싱.

핀 배치는 시드를 고정한 난수라 같은 개수면 매번 같다. 지구 텍스처는 three-globe 예제의 `earth-day.jpg`(1600×800)다.
