# 지구본 여행일지 요구사항 명세서

Sep 30, 2026 · @깡통

**버전 1.3**: 1.1에서 역지오코딩, 여행·친구·차단·탈퇴 규칙, 지구본 예외 화면, 사진 파일 동기화, 권한 재계산 정책을 보완했다(FR-17\~24, NFR-07\~10). 1.2에서 바다 좌표를 선택할 수 없게 했다. 1.3에서 사진으로 기록하기(FR-25)와 여행 타임랩스(FR-26)를 추가했다.

## 개요

지구본 여행일지는 다녀온 곳을 3D 지구본 위에 기록하고 돌려 보며 추억을 꺼내 보는 모바일 우선 반응형 웹 서비스다. 모든 일지는 좌표와, 서버가 역지오코딩으로 붙인 국가·행정구역 정보를 가진다. 일지마다 공개 범위를 정해 다른 회원과 지구본을 서로 구경한다.

**사용자**: 가입한 회원. 로그인하지 않은 사람은 가입·로그인 화면 외에는 볼 수 없다.

**용어 정의**

- **일지**: 한 장소에 대한 기록. 위치, 국가·행정구역, 제목, 방문 날짜, 메모, 사진으로 구성된다.
- **일지 초안**: 사진으로 기록하기(FR-25)가 사진을 묶어 만든 저장 전 일지. 사용자가 확인해야 일지가 된다.
- **여행**: 일지를 묶는 선택적 단위. 여행 하나에 일지 여러 개가 속하고, 일지는 여행에 속하지 않거나 여행 하나에만 속한다.
- **타임랩스**: 일지를 방문 순서대로 따라가며 지구본이 돌고 경로를 그리는 재생 화면(FR-26).
- **공개 범위**: 일지마다 비공개, 친구 공개, 전체 공개 중 하나를 정한다.
- **전체 공개**: 가입한 회원 전체에게 보인다. 로그인하지 않은 사람에게는 보이지 않는다.
- **친구 관계 상태**: PENDING(요청 보냄, 수락 대기), ACCEPTED(친구), BLOCKED(한쪽이 상대를 차단함).
- **차단**: 한 회원이 상대 회원을 막는 것. 방향이 있어서, 차단한 쪽만 해제할 수 있다.
- **역지오코딩**: 좌표를 국가 코드, 행정구역명, 장소명으로 바꾸는 것.
- **국가 코드**: ISO 3166-1 alpha-2(예: KR)와 alpha-3(예: KOR).
- **핀 클러스터**: 화면에서 겹치는 핀 여러 개를 개수가 적힌 하나의 표시로 묶은 것.
- **소프트 삭제**: 데이터를 바로 지우지 않고 삭제 표시만 남겨 서비스에서 보이지 않게 하는 것.
- **서명 URL**: 정해진 시간이 지나면 열리지 않는 사진 접근 주소.

### 세부 규칙

**FR-06 위치 지정과 역지오코딩**

- 좌표는 WGS84 기준 위도(-90\~90), 경도(-180\~180)를 소수점 6자리까지 저장한다.
- 역지오코딩은 일지를 저장하거나 위치를 수정할 때 서버가 한다. 클라이언트가 보낸 국가 코드는 받지 않는다.
- 저장 항목: 국가 코드 alpha-2·alpha-3, 1단계 행정구역(시·도), 2단계 행정구역(시·군·구), 표시용 장소명.
- 장소 검색으로 지정해도 검색 결과의 좌표만 쓰고, 국가·행정구역은 서버가 같은 방식으로 채운다.
- 바다처럼 국가가 없는 좌표는 선택할 수 없다. 지구본에서는 국가 영역만 눌리고, 장소 검색 결과에서도 국가가 없는 곳은 뺀다. 서버도 역지오코딩 결과에 국가가 없으면 저장을 거부한다(화면에서만 막으면 API를 직접 호출해 우회할 수 있다).
- 국경·분쟁 지역: 지오코딩 제공자의 결과를 그대로 쓴다. 사용자는 국가 코드를 고칠 수 없고 장소명만 고칠 수 있다.
- 지오코딩 API가 실패하거나 3초 안에 응답하지 않으면 좌표만으로 저장하고 "국가 확인 대기" 상태로 둔다. 서버가 주기적으로 재시도해 채운다.

**FR-09 여행**

- 관계는 여행 1 : 일지 N이다. 일지는 여행에 속하지 않거나 여행 하나에만 속한다.
- 속성: 제목(필수, 1\~50자), 시작일(필수), 종료일(선택, 시작일 이후), 설명(선택, 최대 500자).
- 여행 상세는 속한 일지를 방문 날짜 순으로 보여 준다.
- 일지 작성·수정 화면에서 여행을 고르거나 뺄 수 있고, 여행 상세에서 기존 일지를 추가하거나 뺄 수 있다.
- 방문 날짜가 여행 기간 밖이어도 묶을 수 있다. 화면에 안내만 띄운다.
- 여행을 삭제하면 속한 일지는 남기고 여행 연결만 푼다.
- 여행에는 공개 범위가 없다. 보이는지 여부는 공개 범위 규칙을 따른다.
- 내 일지만 내 여행에 묶을 수 있다.

**FR-11·20·21 친구와 차단**

- 거절, 요청 취소, 친구 삭제는 관계 기록을 지운다. REJECTED 상태는 두지 않으며, 거절당해도 다시 요청할 수 있다.
- 상대가 나에게 보낸 PENDING 요청이 있는데 내가 요청하면, 새 요청을 만들지 않고 수락으로 처리한다.
- 차단하면 기존 친구 관계나 요청은 사라지고 BLOCKED가 된다.
- 차단 관계에서는 양쪽 모두 서로의 지구본, 일지, 검색 결과를 볼 수 없고, 차단당한 쪽은 요청을 보낼 수 없다.
- 차단당한 쪽에는 차단 사실을 알리지 않고 "찾을 수 없음"으로 보인다.
- 차단을 해제해도 친구 관계는 복구되지 않는다.

**FR-19 회원 탈퇴**

- 비밀번호를 다시 입력해 본인 확인을 한 뒤 탈퇴한다.
- 탈퇴 즉시 로그인할 수 없고, 모든 일지·여행이 다른 회원에게 보이지 않으며, 검색에서 빠진다. 친구 관계·요청·차단 기록은 바로 삭제한다.
- 회원 정보는 소프트 삭제로 30일 보관한 뒤, 회원·일지·여행·사진 파일을 영구 삭제한다(NFR-09).
- 유예 기간 중에는 같은 이메일로 다시 가입할 수 없다. 닉네임은 탈퇴 즉시 풀려서 다른 회원이 쓸 수 있다.

**FR-23 빈 상태 화면**

- 내 일지가 0개: 지구본은 그대로 보여 주고 "첫 여행지를 기록해 보세요" 안내와 일지 작성 버튼을 띄운다.
- 다른 회원 지구본에서 볼 수 있는 일지가 0개: "아직 볼 수 있는 기록이 없어요"라고만 안내한다. 비공개 일지가 있는지는 드러내지 않는다.
- 친구, 받은 요청, 검색 결과가 0개인 목록에도 안내 문구와 다음 행동(예: 닉네임 검색하기)을 둔다.

**FR-25 사진으로 기록하기**

- 한 번에 최대 100장까지 고를 수 있다. 사진 형식과 용량 제한은 NFR-02를 따른다.
- 사진의 촬영 위치(GPS)와 촬영 시각을 읽은 뒤, 저장 전에 EXIF를 지운다(NFR-02).
- 같은 날짜에 서로 1km 이내에서 찍은 사진을 하나의 일지 초안으로 묶는다. 1km는 기본값이며 운영하면서 조정한다.
- 초안의 위치는 묶인 사진 좌표의 중심, 방문 날짜는 첫 사진의 날짜, 제목은 역지오코딩한 장소명으로 채운다. 사진이 5장을 넘으면 처음 5장을 고르고, 사용자가 바꿀 수 있다.
- 위치 정보가 없거나 바다 좌표인 사진은 "위치를 정해야 하는 사진"으로 따로 모은다. 사용자가 위치 선택 화면(FR-06)에서 위치를 정하면 초안이 된다.
- 사용자는 초안 목록에서 각 초안을 고치거나 뺄 수 있고, 확인한 초안만 일지로 저장된다. 공개 범위 기본값은 비공개다.
- 올린 사진을 새 여행으로 묶는 선택지를 준다. 여행 기간은 사진 날짜 범위로 채운다.
- 묶기는 서버에서 비동기로 처리하고 진행 상황을 보여 준다. 화면을 닫아도 처리는 계속되고, 다시 열면 초안 목록이 이어진다.
- 저장하지 않은 초안과 사진은 24시간 뒤 정리한다(NFR-08).

**FR-26 여행 타임랩스**

- 재생 범위는 여행 하나 또는 연도 하나다.
- 일지를 방문 날짜 순으로 따라간다. 같은 날이면 촬영 시각 순, 촬영 시각이 없으면 작성 순이다.
- 지구본이 다음 장소로 회전하며 이전 장소와 호(arc)로 잇고, 장소마다 대표 사진과 제목을 잠깐 보여 준다.
- 재생, 일시정지, 처음부터 다시, 속도(1배·2배)를 조절할 수 있다.
- 다른 회원의 타임랩스는 공개 범위 규칙에 따라 볼 수 있는 일지만으로 만든다.
- 영상 저장과 공유는 이후 범위다(FR-27).

## 공개 범위 규칙

일지를 볼 수 있는지는 일지의 공개 범위와 보는 사람의 관계로 서버가 정한다. 차단 관계는 공개 범위보다 우선한다.

| 공개 범위 | 본인 | 친구 | 그 외 회원 | 차단 관계(어느 쪽이든) |
| --- | --- | --- | --- | --- |
| 비공개 | 보임 | 안 보임 | 안 보임 | 안 보임 |
| 친구 공개 | 보임 | 보임 | 안 보임 | 안 보임 |
| 전체 공개 | 보임 | 보임 | 보임 | 안 보임 |

**판정 순서** (위에서부터 먼저 걸리는 규칙을 적용)

1. 로그인하지 않음: 거부한다.
2. 작성자가 탈퇴함: 없는 일지로 응답한다.
3. 둘 중 한쪽이 상대를 차단함: 없는 일지로 응답한다.
4. 보는 사람이 작성자 본인: 모두 보인다.
5. 친구 관계가 ACCEPTED: 친구 공개와 전체 공개가 보인다.
6. 그 외 회원: 전체 공개만 보인다.

**세부 규칙**

- 지구본의 핀, 클러스터 개수, 방문 국가 색칠, 여행 목록과 상세는 보는 사람이 볼 수 있는 일지만으로 계산한다.
- 여행은 볼 수 있는 일지가 하나 이상일 때만 보이고, 여행 상세에는 볼 수 있는 일지만 나온다.
- 권한은 요청마다 DB의 현재 관계로 다시 계산한다. 친구 삭제, 차단, 공개 범위 변경은 바로 다음 요청부터 반영된다. 이미 떠 있는 화면은 새로고침하거나 다음 요청을 보낼 때 갱신된다.
- MVP에서는 권한 판정 결과를 캐시하지 않는다. 이후 캐시를 도입하면, 친구 관계·차단·공개 범위가 바뀌는 즉시 관련된 두 회원의 캐시를 무효화한다.
- 사진은 만료 10분짜리 서명 URL로만 내려준다. 권한이 사라져도 이미 받은 URL은 만료 전까지 열릴 수 있으므로 만료 시간을 짧게 유지한다.

| NFR-01 | 성능·화면 | 휴대폰 브라우저에서 핀 1,000개가 있어도 지구본과 타임랩스가 30fps 이상으로 돌아간다(FR-22 클러스터링 전제). 모바일 우선 반응형 웹 | 1.3 변경 |
| NFR-02 | 사진 | 장당 10MB 이하, JPG·PNG·WebP·HEIC만 허용. 서버에서 긴 변 2,048px로 줄이고 목록용 400px 썸네일을 만든다. 촬영 위치·시각을 읽은 뒤 EXIF 메타데이터는 제거한다 | 1.3 변경 |
| NFR-03 | 권한 | 서버가 공개 범위 규칙의 판정 순서로 볼 수 있는 일지만 응답한다. 프론트에서 숨기는 방식은 허용하지 않는다 | 1.1 변경 |
| NFR-04 | 보안 | 비밀번호는 BCrypt 해시로 저장하고, 모든 통신은 HTTPS로 한다 | 없음 |
| NFR-05 | 개인정보 | 일지를 전체 공개로 바꿀 때 "가입한 모든 회원에게 위치가 보인다"는 확인 창을 띄운다 | 없음 |
| NFR-06 | 인증 | 가입, 로그인, 닉네임·이메일 중복 확인을 제외한 모든 API는 로그인한 회원만 호출할 수 있다 | 1.1 변경 |
| NFR-07 | 파일 동기화 | 일지 삭제 시 모든 사진, 일지 수정 시 뺀 사진을 저장소(S3 등)에서 지운다. DB 트랜잭션이 커밋된 뒤에 지우고, 실패한 삭제는 재시도 목록에 넣어 하루 한 번 다시 처리한다 | 1.1 신규 |
| NFR-08 | 파일 정리 | 사진은 임시로 먼저 올리고 일지를 저장할 때 확정한다. 24시간 넘게 확정되지 않은 파일과 초안, DB에 기록이 없는 파일은 매일 배치로 삭제한다 | 1.3 변경 |
| NFR-09 | 데이터 삭제 | 탈퇴 회원은 30일 뒤 배치로 회원·일지·여행·사진 파일을 영구 삭제한다. 일지·여행 삭제는 소프트 삭제 없이 즉시 영구 삭제한다 | 1.1 신규 |
| NFR-10 | 외부 API | 지오코딩 API는 서버에서만 호출하고 키는 서버 환경변수로 관리한다. 응답 제한 시간은 3초이며, 실패 시 FR-06 규칙을 따른다 | 1.1 신규 |
| NFR-11 | 비동기 처리 | 사진 100장을 올려도 화면이 멈추지 않는다. 업로드는 사진별로 나눠 보내고, 묶기와 역지오코딩은 서버 작업으로 처리하며 진행률을 보여 준다. 같은 위치의 역지오코딩 결과는 재사용해 외부 API 호출을 줄인다 | 1.3 신규 |

## 결정 이력

최신 결정이 위에 온다.

| 버전 | 항목 | 결정 | 근거 |
| --- | --- | --- | --- |
| 1.3 | 차별화 기능 | 사진으로 기록하기(FR-25)와 여행 타임랩스(FR-26)를 MVP에 추가 | "사진만 올리면 지구본이 채워지고, 영상처럼 돌려 볼 수 있는 앱"으로 다른 여행 기록 앱과 구분 |
| 1.3 | 주 기록 방법 | 사진으로 기록하기를 주 진입점으로, 직접 기록은 보조로 유지 | 위치 없는 사진(메신저로 받은 사진, 캡처), 바다 위 사진, 사진 없는 기억이 있어 직접 기록과 위치 선택 화면이 꼭 필요함 |
| 1.3 | 사진 묶기 기준 | 같은 날짜, 서로 1km 이내 | 가정. 실제 사진으로 시험하며 조정 |
| 1.3 | 사진 메타데이터 | 촬영 위치·시각을 읽은 뒤 EXIF 제거 | 자동 기록에 위치·시각이 필요하지만, 원본 위치 정보가 공개 범위를 우회해 노출되면 안 됨 |
| 1.3 | 타임랩스 영상 저장 | 이후 범위(FR-27) | 재생부터 완성하고, 영상 생성은 난이도와 서버 비용을 보고 결정 |
| 1.3 | 주제 | 개인화 학습 앱으로 바꾸지 않고 여행일지에 차별화 기능을 더함 | 설계 산출물 세 개가 이미 있어 지금 바꾸면 비용이 큼. 학습 앱은 두 번째 프로젝트 후보 |
| 1.1 | 역지오코딩 위치 | 서버에서 수행, 클라이언트의 국가 코드는 받지 않음 | 클라이언트 값은 조작할 수 있어 색칠·통계가 틀어짐 |
| 1.1 | 바다 좌표 | 선택 불가. 지구본·장소 검색·서버 모두에서 막음 (1.2에서 변경) | 사용자 결정. 1.1의 "저장 허용" 안은 폐기 |
| 1.1 | 여행과 일지 | 여행 1 : 일지 N, 여행 삭제 시 일지는 유지 | 일지가 기록의 기본 단위임 |
